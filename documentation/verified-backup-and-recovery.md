# Procedimiento Full Recovery
En la documentación de la semana 5 esta el manual paso a paso de como recuperarse de un desastre, comprobando estado del sistema y servicios criticos, localizar backups y ver logs de errores, restaurar los datos del backup y verificar que ha funcionado

# Testeo del recovery
Usar un directorio alternativo como /tmp/restore-test y ver si el backup ha funcionado, verificar la integridad de los datos y utilizar el script verify-backup.sh 

# Cuanto tiempo toma hacer la recuperación?
Un RTO aceptable seria de 1 a 2 horas.
