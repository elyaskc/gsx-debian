# Limites a los usuarios del grupo greendevcorp

Se ha modificado el archivo limits.conf para añadir nuevos límites al final:
- Hard limit: Cada usuario del grupo greendevcorp puede tener un máximo de 50 procesos.
- Hard limit: Cada usuario del grupo greendevcorp puede tener abiertos un máximo de 1024 archivos.
- Hard limit: Cada usuario del grupo greendevcorp puede utilizar un máximo de 512MB de memoria.
- Hard limit: Cada usuario del grupo greendevcorp puede usar la CPU un máximo de 10 minutos por proceso.
